# 章扉と本文と表と演習のPDF試作

本文教材の15ページ、20ページ、69ページと、演習ガイド20ページをMarkdownから生成しました。見た目の比較には元PDFと対応する固定配置版を使い、自動改ページの確認には同じMarkdownの内容を流し込む版を使います。教材本文やサンプルコードのバージョン改訂は行っていません。

## 確認するファイル

出力先はリポジトリ直下の `output/pdf/prototype/extended/` です。

| ファイル | 内容 |
| --- | --- |
| `comparisons.pdf` | 4種類の左右比較。左が元PDF、右が試作 |
| `samples.pdf` | 試作した4ページのみ |
| `pagination.pdf` | 自動組版と増量検証をまとめた19ページ |
| `checks.json` | ページ数、識別子の欠落・分離、はみ出しの検証結果 |
| `chapter/body/table/exercise-comparison.png` | 種類別の左右比較画像 |
| `*-overlay.png` | 元PDFと試作を50%ずつ重ねた144dpi画像 |
| `*-difference.png` | 画素差がしきい値を超えた場所を黒く表示 |

比較PDFは、章扉・通常本文・比較表・演習の順です。

## 見た目の再現結果

| 編集元 | 比較基準 | 結果と残る差 |
| --- | --- | --- |
| `chapter.md` | 本文15ページ | オレンジの章番号、章題、目標、箇条書きを再現。章題の字間や記号の形状に差が残る |
| `body.md` | 本文20ページ | 見出し、段落、強調、行間を再現。細かな字幅、強調の太さに差が残る |
| `table.md` | 本文69ページ | 3列の比較表、赤字、下線を編集可能な文字と表で再構成。Wordの二重に見える細い罫線、セルの内側余白、字間には差がある |
| `exercise.md` | 演習20ページ | 設問、箇条書き、字下げ、余白を再現。見出しの太さや日英混在部分の字間に差が残る |

ページ全体を画像として貼り付ける方式ではありません。固定配置版ではMarkdownに元の行末を残し、表の各行は必要な場合に横幅を微調整してセル内へ収めています。自動改ページ版では元の行末指示を外し、現在の幅で折り返しを計算します。このため、元PDFと同じ改ページ位置になるとは限りません。

`checks.json` の画素差は白地を含むRGB差の平均です。一致率や教材全体の品質点数としては扱いません。

## 自動改ページの検証結果

`pagination.pdf` 内のページ位置は次のとおりです。検証のための繰り返し文章や識別番号は、このPDFだけに入っています。

| ページ | 条件 | 結果 |
| --- | --- | --- |
| 1 | 通常本文を自動組版 | 1ページに収まり、はみ出しなし |
| 2〜4 | 通常本文を4回、28段落 | 見出しの取り残し・はみ出しなし |
| 5〜6 | 1つの長い段落に文章を20回追加 | 2ページへ継続。全文照合で文字の欠落・重複なし。各ページの本文は37行と24行 |
| 7〜13 | 比較表を60行へ増量 | 全ページに列見出しを反復。60行の欠落・ページをまたぐ行の分断なし |
| 14〜17 | 演習を24問へ増量 | 各設問とその箇条書きが同じページに収まる |
| 18〜19 | 本文の後ろにスライドと説明を追加 | 図と説明が一緒に次ページへ移動 |

検証はPDF内の文字・座標とTypstの配置位置を読み取り、条件を満たさない場合はスクリプトを失敗させます。出力ページの画像も確認しています。本文は幅・行間に応じて改ページし、表は行単位、演習は設問単位、図は説明とのセットで移動します。

今回確認した範囲ではレイアウトの崩れは検出されませんでした。1ページより大きい単一の表セル・設問・図、複雑な結合セル、全教材を通した章番号や索引の連動は今回の対象外です。

## 再生成

前の85ページ試作と同じPython依存関係、Pandoc、Windowsフォントを使用します。

```powershell
.\.venv\Scripts\python.exe docs/prototype/extended/build_extended.py
```

元教材PDF2冊と、前の試作で保存した `docs/prototype/assets/findall-slide.svg` が必要です。元PDFのハッシュを検証結果に記録します。自動生成するTypstファイルと作業用フォントは `tmp/extended-prototype/` に保存し、Git管理には含めません。静的フォントを明示して、同名の可変フォントが選ばれることによる字幅の変化を避けています。
