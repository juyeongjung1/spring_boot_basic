| 要素 | JDBC | Spring Data JPA |
| :--- | :--- | :--- |
| 外部ライブラリ<br>の依存 | JDBC ドライバー(mysql-connector-j.jar）を<br>[手動でプロジェクトに追加する]{.red .underline}必要があ<br>る。ダウンロードやビルドパスの設定など<br>の追加作業が伴う。 | Maven で[必要なライブラリが自動的に管理]{.red .underline}<br>される。手動での追加作業は不要。 |
| ハードコーディ<br>ング | [接続情報（URL、ユーザー名、パスワード）<br>がソースコード内に直接書かれる]{.red .underline}ことが多<br>く、セキュリティリスクになり得る。環境の変<br>更があるたびにコードの変更が必要。 | [接続情報は外部の設定ファイル<br>（application.properties）に記載]{.red .underline}するため、<br>セキュリティが向上し、環境に応じた変更も<br>容易。 |
| 冗長なコード | 接続や例外処理などのために冗長なコー<br>ドが必要。[読みにくく、エラーが発生しやす<br>い。]{.red .underline} | JPA リポジトリインターフェースを使用するこ<br>とで、冗長なコードを大幅に削減。より[シン<br>プルで読みやすい]{.red}。 |
| 例外処理の必<br>要性 | DriverManager.getConnection メソッドが<br>接続失敗時にSQLException をスローする<br>ため、追加の[例外処理コードが必要]{.red}。 | RuntimeException を使用するため、[明示<br>的な例外処理が不要になる場合が多い]{.red}の<br>で、コードがシンプル。 |
| リソース管理 | 開いたデータベース[接続を適切に閉じる責<br>任]{.red}が開発者にある。これを怠るとリソース<br>リークのリスクがある。 | リソース管理をフレームワークが行うため、<br>開発者はリソースリークを[気にする必要が<br>少ない]{.red}。 |

Spring Data JPA は、よりシンプルで安全、そして効率的なデータアクセスを提供することで、デ\
ータベースプログラミングを容易にします。
