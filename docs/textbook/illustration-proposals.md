# 挿絵の検討結果

前回の提案後、本文・付録・演習の全19章と既存図を再確認し、小型の新規9図を生成・挿入しました。図の配置と画像は [挿入済み一覧](illustrations.md)、正確な生成プロンプトは [カタログ](illustrations.json) にあります。

| 前回の案 | 今回の扱い |
| --- | --- |
| MVCの全体フロー | 既存の全体図を活かし、Modelのデータとテンプレートの合成に絞って追加 |
| Entityの1行とJavaオブジェクト | 既存図で十分なため、Repositoryの0件以上／0または1件の対比へ変更 |
| セッション | IDとサーバー側データを分ける小型図を挿入 |
| 入力チェック | エラー表示／次の処理の分岐図を挿入 |
| 外部キー | DBのID値とJavaの参照を対比する図を挿入 |
| エラー原因の調査 | Caused by:から例の該当行を確認する図を挿入 |

追加調査で、Mavenの宣言とライブラリ、共通レイアウトの合成、画面幅による配置の切替も採用しました。言語別メッセージは既存の参考欄を分断しない構成としました。既存DI図はそのまま縮小しています。
