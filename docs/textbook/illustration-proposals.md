# 挿絵の追加候補

今回挿入するのは、第3章「依存性の注入」のリモコンの挿絵です。以下は追加を検討するための候補で、本文には挿入していません。

| 挿入候補 | 描く内容 | 伝わりやすくなる点 |
| --- | --- | --- |
| 第2章・MVCの流れ（原本38ページ） | ブラウザー→Controller→Model→Thymeleaf→画面を、1回のリクエストに沿った矢印で描く | リクエストと画面表示の順序、担当の違い |
| 第3章・EntityとRepository（原本76〜78ページ） | DBの1行、Productオブジェクト、Repositoryを並べ、データの対応を色で揃える | テーブルとJavaの世界の対応 |
| 第4章・セッション（原本145ページ付近） | ブラウザーに持つセッションIDと、サーバーに保管するログイン情報を別の場所に描く | ブラウザーにユーザー情報そのものを保存するとの誤解を防ぐ |
| 第4章・入力チェック（原本150ページ付近） | 入力→Form→検証→エラー付き画面／正常処理の二股を描く | BindingResultと画面への戻し方 |
| 第6章・外部キーと関連（原本197〜200ページ） | 商品とカテゴリのカードを、外部キーとJavaの参照の両方で結ぶ | category_idとCategory型フィールドの役割 |
| 付録B・エラーの調査 | 外側の例外→Caused byの原因→自分のコードの該当行を、拡大していく図にする | 長いスタックトレースの読み始める位置 |

次に追加するなら、MVCの流れとセッションの図が候補です。リモコンの挿絵と同じ白背景・青緑系の配色に揃えます。
