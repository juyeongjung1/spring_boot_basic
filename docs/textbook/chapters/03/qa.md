# 第3章 Spring Data JPA 検証記録

## 対象と生成結果

- 元PDF: 63〜132ページ
- 元位置再現版: 70ページ
- 自動組版版: 59ページ
- 図版: 69点、うち編集用PPT原本16点
- Markdown表: 5個
- 本文の改訂、JavaやSpring Bootの版変更はこの工程では行っていない。

## 自動検査

元位置再現版は全70ページの文字照合が一致した。自動組版版も本文文字の照合が一致し、見出しの孤立、図版分断、短いコード枠分断、短い表の分断、操作説明群の分断、ページ外へのはみ出しを検出しなかった。小さいDB設定表が改ページで分かれる問題は、表の実寸計測による一体保持で解消した。最終検査位置は出力先のchecks.jsonに記録される。

元PDFとの画像差は、RGB各成分0〜255に対する絶対差平均で0.2276。最大は元PDF114ページの0.7705。この値は完全な画素一致を意味するものではなく、フォントやSVG描画の微差を含む。

## 画像による確認

元位置再現版70ページ・自動組版版59ページを縮小画像で確認した。特に元PDF67・69・73ページの表、74ページの点線吹き出し、94ページのWingdings矢印、98・102ページの入力画面、109・110ページの複合図、113ページのコードに重なる矢印を実寸画像でも確認した。元位置版の比較表、色、罫線、文字位置、矢印・吹き出しの全形に欠けがないことを確認した。

図版ROIと元PDFのベクトル図形の交差も監査した。74ページの点線吹き出しを図版に含め、98・102ページの分割された画面画像を外周枠ごと統合した。コード強調枠の表誤検出は除外した。Wingdingsの矢印5箇所は共通処理で元フォントを保持する。

自動組版版では、71ページの黄色い吹き出しと113ページの黒い矢印がコード直下へ移る。コード本文をMarkdownで改訂できる状態を保つための扱いであり、元位置再現版では元の重ね位置を保っている。

PPT原本16点はWord埋め込みファイルとのバイト照合が一致した。元位置再現版は元の改ページを保持する。自動組版版は本文量に従って改ページするため、ページ数・ページ内位置は変化する。各版は同じchapter.mdから生成される。
