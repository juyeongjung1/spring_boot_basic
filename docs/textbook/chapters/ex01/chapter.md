[演習]{.s010}[1\.1.&#32;]{.s011}[フレームワークとは]{.s010}

:::

::: {#p009-b02 .paragraph}

[問題1:フレームワークを使用する利点は何ですか？]{.s012}

[a)&#32;]{.s005}[システム開発の時間と労力が増える。]{.s013}

[b)&#32;]{.s005}[特定の種類のシステムをより速く、効率的に作ることができる。]{.s013}

[c)&#32;]{.s005}[オブジェクト指向プログラミングを学ぶ必要がない。]{.s013}

[d)&#32;]{.s005}[エラーメッセージが一切表示されなくなる。]{.s013}

:::

::: {#p009-b03 .paragraph}

[問題2:フレームワークを使う際の注意点はどれですか？]{.s012}

[a)&#32;]{.s005}[フレームワークは自由度が高く、ルールに従う必要がない。]{.s013}

[b)&#32;]{.s005}[エラーメッセージは無視しても良い。]{.s013}

[c)&#32;]{.s005}[フレームワークに定められたルールや方法に従う必要がある。]{.s013}

[d)&#32;]{.s005}[データベースに接続する際はフレームワークを使わない方が良い。]{.s013}

:::

::: {#p009-b04 .heading}

[演習]{.s010}[1\.2. Spring Framework]{.s011}

:::

::: {#p009-b05 .paragraph}

[問題1: Spring Framework の特徴はどれですか？]{.s012}

[a) DI]{.s005}[（依存性注入）を使用しない。]{.s013}

[b) MVC]{.s005}[（]{.s013}[Model-View-Controller]{.s005}[）モデルをサポートしない。]{.s013}

[c)&#32;]{.s005}[他のフレームワークやライブラリと組み合わせて利用することが可能。]{.s013}

[d) Struts2]{.s005}[&#32;や、]{.s013}[Seasar2]{.s005}[&#32;などのフレームワークと競合している。]{.s013}

:::

::: {#p009-b06 .paragraph}

[問題2: Spring Framework におけるDI（依存性注入）の主な目的は何ですか？]{.s012}

[a)&#32;]{.s005}[オブジェクト間の依存関係をハードコーディングする。]{.s013}

[b)&#32;]{.s005}[よく使われるクラスを簡単に呼び出し、プログラムの柔軟性と再利用性を高める。]{.s013}

[c) Java]{.s005}[&#32;の基本的な構文を変更する。]{.s013}

[d) Web]{.s005}[&#32;ページのデザインとレイアウトを管理する。]{.s013}

:::

:::

::: {#p010-b01 .heading}

[演習]{.s010}[1\.3. Spring Boot]{.s011}[&#32;とは]{.s014}

:::

::: {#p010-b02 .paragraph}

[問題1:Spring Boot による初期環境構築のメリットは何でしょうか？]{.s012}

[a) 設定が全く必要ない。]{.s013}

[b) 設定を自動化して初期環境構築を簡単にする。]{.s013}

[c) 設定がより複雑で細かい。]{.s013}

[d) 開発者がすべての設定を手動で行う必要がある。]{.s013}

:::

::: {#p010-b03 .paragraph}

[問題2: Spring Boot が提供するBean に関する機能として正しいものはどれですか？]{.s012}

[a)&#32;]{.s005}[必要な&#32;]{.s013}[Bean]{.s005}[&#32;をすべて手動で登録する必要がある。]{.s013}

[b)&#32;]{.s005}[開発者が用意したクラスを自動で&#32;]{.s013}[Bean]{.s005}[&#32;として登録してくれる。]{.s013}

[c) Bean]{.s005}[&#32;の登録機能は提供されていない。]{.s013}

[d) Bean]{.s005}[&#32;を登録するには&#32;]{.s013}[XML]{.s005}[&#32;ファイルが必須である。]{.s013}

:::

::: {#p010-b04 .heading}

[演習]{.s010}[1\.4. Maven]{.s011}[&#32;でライブラリ管理]{.s014}

:::

::: {#p010-b05 .paragraph}

[問題1: Maven を使用する主な理由は何ですか？]{.s012}

[a)&#32;]{.s005}[プロジェクトのデザインを改善するため。]{.s013}

[b)&#32;]{.s005}[ソースコードの書き方を自動化するため。]{.s013}

[c)&#32;]{.s005}[ライブラリのダウンロードと参照関係の管理を自動化するため。]{.s013}

[d)&#32;]{.s005}[データベース接続を自動で設定するため。]{.s013}

:::

::: {#p010-b06 .paragraph}

[問題2: Maven を使用して、どのようにライブラリを管理すればいいですか？]{.s012}

[a)&#32;]{.s005}[ライブラリを手動でダウンロードしてプロジェクトに追加する。]{.s013}

[b)&#32;]{.s005}[ライブラリの情報を&#32;]{.s013}[pom.xml]{.s005}[&#32;ファイルに記述して、]{.s013}[Maven install]{.s005}[&#32;を実行する。]{.s013}

[c)&#32;]{.s005}[すべてのライブラリを個別にインストールする。]{.s013}

[d)&#32;]{.s005}[ライブラリの情報をプロジェクトの&#32;]{.s013}[README]{.s005}[&#32;ファイルに記述する。]{.s013}
