07-explanation-1
コードの読み方
1行目
<div class="container">
今回のサンプルでは、外側を container でコンテナを作っています。画面の中央にコンテンツが配置されます。もし、container-fluid にすると、横幅いっぱいに変わります。


07-explanation-2
コードの読み方
2行目
<div class="row">
 コンテナの中に、row をclass 属性として持つdiv 要素を入れます。後述のカラムを配置するためにも、必ずrow が必要です。まるでtable 要素に、<tr>がないと、<td>も書けないのと同じです。
3～5行目
<div class="col-6 bg-primary-subtle">Column 1</div>
<div class="col-3 bg-danger-subtle">Column 2</div>
<div class="col-3 bg-success-subtle">Column 3</div>
1 つのrow の中に、複数のカラムを配置できます。このサンプル通りだと、以下のように表示されます。


07-explanation-3
コードの読み方
6～7行目
    </div> <!-- END row1-->
</div><!-- END container-->
グリッドシステムでは、<div>要素を使うことが多いので、閉じタグだけでは、どの要素の閉じタグなのか、区別がつきません。そのため、どの要素の閉じタグなのかを明確にするため、コメントを記載することが多いです。
特に、row が複数ある場合は「END row1」や、「END row2」とかでコメントを残すことで実際の範囲も読みやすくなるので、重要です。


07-explanation-4
コードの読み方
5行目
<div class="col-md-3"> <!-- START sidebar -->
 フォームとは直接関係がないコードですが、横幅の3 割のみ占めるように、限定をさせることで、左サイドバーのようなレイアウトを作ることができます。検索バーは、サイドバーに配置させることが多いので、予めカラムを生成しました。
8行目
<form class="row">
<div>ではなく、<form>要素をrow として生成すると、フォームを別途の行として扱えることができます。
9行目・13行目
<div class="col-8">
<div class="col-4">
入力フォームに8、ボタンに4 の割合でカラムを生成しています。
10行目
<input type="text" class="form-control"


07-explanation-5
コードの読み方
10行目
<input type="text" class="form-control"
  Bootstrap のフォーム関連クラスの中で、一番大事なクラスです。テキストフォームにこのクラスを付与することで、Bootstrap 式のテキストフォームのデザインを適用することができます。
