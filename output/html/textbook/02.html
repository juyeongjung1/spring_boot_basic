02-explanation-2
コードの読み方
行番号該当コード意味・補足

このビューの特徴として、2 行目に注目してください。ここでは、Spring Boot と相性が良いテンプレートエンジン「Thymeleaf」を使用するという宣言をしています。xmlns:th を記載することで、HTML ファイル内でThymeleaf の機能が利用可能になります。

02-explanation-3
コードの読み方
行番号該当コード意味・補足
10 行目
<form th:action = "@{/login}" method="POST">
<form>要素を用いてデータ送信のためのフォームを作成します。この要素のth:action 属性は、フォームデータが送信されるサーバー上のURL を指定できます。Thymeleaf では、ただのaction ではなく、th:action を使うことで、実行環境に変化があってもURL を正しく解決できます。「@」は、アプリケーションのコンテキストパス(基本URL）を、自動生成してくれます。URLが異なるサーバーで実行しても、影響がなくなる効果があります。 ここでは/login がそのURL として指定されています。通常、th:action 属性のURL 先は、@Controller のメソッドを指定します。そして、method という属性がありますが、この属性は一般的なGET 方式の送信ではなく、POST 方式の送信をするという意味です。POST 方式にすると、パスワードがURL に表示されないなどのメリットがあり、隠したいデータを送信する時によく使われます。


02-explanation-4

11 行・12 行目
<p>社員番号 ：<input type = "text" name = "id"/></p>
<p>パスワード：<input type = "password" name = "password"/></p>
<input>要素はユーザがデータを入力するためのフィールドを提供します。type="text"を指定することでテキスト入力フィールドが、type="password"を指定することでパスワード入力フィールドがそれぞれ生成されます。ここで、このフォームのデータは、社員番号という日本語で認識されるのではなく、name 属性の値で認識されます。今回は、「id」と「password」というnameでデータが送られるということを覚えてください。
13 行目
<input type = "submit" value = "ログイン">
<input type="submit">は送信ボタンを表します。このボタンをクリックすると、フォーム内のデータがth:action 属性で指定されたURL に送信されます。value 属性はボタン上に表示されるテキストを定義します。
