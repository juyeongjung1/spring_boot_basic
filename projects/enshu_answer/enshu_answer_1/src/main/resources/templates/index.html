演習1.1. フレームワークとは

問題1: フレームワークを使用する利点は何ですか？

  • a) システム開発の時間と労力が増える。
  • b) 特定の種類のシステムをより速く、効率的に作ることができる。
  • c) オブジェクト指向プログラミングを学ぶ必要がない。
  • d) エラーメッセージが一切表示されなくなる。

問題2: フレームワークを使う際の注意点はどれですか？

  • a) フレームワークは自由度が高く、ルールに従う必要がない。
  • b) エラーメッセージは無視しても良い。
  • c) フレームワークに定められたルールや方法に従う必要がある。
  • d) データベースに接続する際はフレームワークを使わない方が良い。

演習1.2. Spring Framework

問題1: Spring Frameworkの特徴はどれですか？

  • a) DI（依存性注入）を使用しない。
  • b) MVC（Model-View-Controller）モデルをサポートしない。
  • c) 他のライブラリと組み合わせて利用することが可能。
  • d) Struts2 や、Seasar2 などのフレームワークと競合している。

問題2: Spring FrameworkにおけるDI（依存性注入）の主な目的は何ですか？

  • a) オブジェクト間の依存関係をハードコーディングする。
  • b) よく使われるクラスを簡単に呼び出し、プログラムの柔軟性と再利用性を高める。
  • c) Javaの基本的な構文を変更する。
  • d) Webページのデザインとレイアウトを管理する。

演習1.3. Spring Bootとは

問題1: Spring Bootによる初期環境構築のメリットは何でしょうか？

  • a) 設定が全く必要ない。
  • b) 設定を自動化して初期環境構築を簡単にする。
  • c) 設定がより複雑で細かい。
  • d) 開発者がすべての設定を手動で行う必要がある。

問題2: Spring Boot が提供する Bean に関する機能として正しいものはどれですか？

  • a) 必要な Bean をすべて手動で登録する必要がある。
  • b) 開発者が用意したクラスを自動で Bean として登録してくれる。
  • c) Bean の登録機能は提供されていない。
  • d) Bean を登録するには XML ファイルが必須である。

演習1.4. Mavenでライブラリ管理

問題1: Mavenを使用する主な理由は何ですか？

  • a) プロジェクトのデザインを改善するため。
  • b) ソースコードの書き方を自動化するため。
  • c) ライブラリのダウンロードと参照関係の管理を自動化するため。
  • d) データベース接続を自動で設定するため。

問題2: Mavenを使用して、どのようにライブラリを管理すればいいですか？

  • a) ライブラリを手動でダウンロードしてプロジェクトに追加する。
  • b) ライブラリの情報をpom.xmlファイルに記述して、Maven installを実行する。
  • c) すべてのライブラリを個別にインストールする。
  • d) ライブラリの情報をプロジェクトのREADMEファイルに記述する。
